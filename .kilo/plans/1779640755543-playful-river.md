# Plan: Improve Commit Message Quality

## Status: COMPLETED ✓

## Problem
The generated commit messages sometimes output generic file-based messages like:
`chore: add .kilo/plans/1779637498696-brave-orchid.md`

This violates the system prompt rule: "NEVER output generic messages like 'update files' or 'changed X files'" and fails to describe the *purpose* of changes.

## Root Cause Analysis
1. The Kilo AI model sometimes produces minimal, file-focused responses
2. Current validation only checks conventional commit format, not semantic quality
3. No mechanism to retry with improved prompting when messages are too generic
4. The `cleanCommitMessage` function could allow file-path-heavy descriptions

## Proposed Improvements

### 1. Strengthen System Prompt ✓
Added explicit prohibitions:
- "NEVER describe changes by listing file paths"
- "Focus on the logical change, not the files modified"
- "If you cannot determine the intent, use 'chore: minor changes' instead of listing files"

### 2. Add Semantic Validation ✓
Created `isMessageTooGeneric()` to detect:
- Messages that end with file paths or contain multiple file paths
- Messages with "add", "remove", "update" followed immediately by a file path
- Messages that are just "add <file>", "update <file>", "delete <file>"
- Messages where the description is primarily a file path pattern

### 3. Implement Retry with Feedback ✓
When a generated message fails semantic validation:
- Call the API again with additional user message: "Your previous message described files instead of intent. Generate a message that explains the *purpose* or *intent* of the changes, not which files were modified. Focus on what was accomplished."
- Limit retries to 2 attempts total (original + 1 retry)
- Falls back to manual entry on failure

### 4. Improve Diff Presentation ✓
Added `git status --short --branch` output to show file status codes (A, M, D, R, etc.) at top of diff summary.

### 5. Enhanced Message Cleaning ✓
Updated `cleanCommitMessage()` to strip trailing file paths using regex pattern matching.
